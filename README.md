# Student Registration System
Spring Boot CRUD application with Thymeleaf and an H2 database.

## How to run
1. Install JDK 17 or later.
2. Run `./mvnw spring-boot:run`
3. Open http://localhost:8080
4. H2 console: http://localhost:8080/h2-console (JDBC URL: jdbc:h2:mem:studentdb, user: sa, empty password)
